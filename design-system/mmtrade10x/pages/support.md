# Support override

- Desktop: inbox/list + conversation/detail split view; mobile: one pane at a time with clear back navigation.
- Ticket state, assignee, last update and unread state are visible in text.
- Composer stays above the mobile keyboard, expands for multiline text, and disables send while pending.
- Empty, loading, failed and closed states are distinct.
- Preserve ticket/thread IDs, attachment handling and support state transitions.

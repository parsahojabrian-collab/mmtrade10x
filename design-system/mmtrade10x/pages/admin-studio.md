# Visual Studio override

- Covers Visual Studio, Object Studio, page editor and academy design editor.
- Desktop workbench: left layer/tree panel, central canvas/preview, right inspector, top action bar, bottom status/viewport controls.
- Panels have independent scroll; canvas remains the primary focal area.
- Mobile: switch panels using explicit tabs/drawers; do not compress all three columns into one tiny grid.
- Show selected object, unsaved state, preview mode, publish state and error state distinctly.
- Preserve iframe bridge, object model, selection IDs, history, drag alternatives, save/publish APIs and dirty/busy guards.

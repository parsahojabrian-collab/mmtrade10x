# Mini App home override

- Mobile-first fintech home, not an admin dashboard squeezed onto a phone.
- First screen: identity/account context, one primary action, concise progress/status, and no more than 4–5 quick actions.
- Bottom navigation has at most five destinations, persistent active state and safe-area padding.
- Use bento only for summary cards; avoid bento for long tables or forms.
- Keep Persian RTL reading order while numeric IDs, URLs and symbols remain LTR where appropriate.

# Security and access override

- Covers admins, roles, section permissions, Telegram team, and audit.
- Permission editor is a comparison matrix on desktop and grouped permission cards on mobile.
- Distinguish read/write/none with text labels, not color alone.
- Require explicit confirmation for role changes and deactivation.
- Audit records are read-only, filterable, timestamped and searchable; identifiers render LTR.
- Preserve authorization checks and never expose secrets or full tokens.

# Content management override

- Covers page manager, pages/popups, route manager, home links, bottom navigation, media, and publication workflows.
- Use a content inventory with status, page slug, updated time, and row actions.
- Editor entry and preview are distinct actions; draft/published state is explicit.
- Form fields use labels, helper text, validation and unsaved-change protection.
- Media library uses responsive thumbnail grid with file metadata and selection state.
- Preserve revision checks, publish safeguards, slug routes and all editor IDs.

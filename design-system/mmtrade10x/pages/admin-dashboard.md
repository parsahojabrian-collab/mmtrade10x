# Admin dashboard override

- Pattern: Data-Dense Dashboard; 12-column grid.
- First row: 3–5 verified KPI cards only (active users, registrations, completion, operational health where available).
- Main row: growth line chart beside activity/health summary; use real API data only.
- Lower row: recent activity table and actionable alerts.
- Keep global header compact; no marketing hero, giant decorative title, or empty glass cards.
- Mobile: KPI cards become 2 columns then 1; chart stacks above activity; no horizontal page scroll.

# Users and communication override

- Covers `users`, `tickets`, `outreach`, `notifications`, `followups`, `growth`, `campaigns`, and `tracking`.
- Header: title, concise description, one primary action.
- Toolbar: search, role/status/source filters, active filter chips, reset, export only if existing backend supports it.
- Desktop table: sticky header, compact readable rows, clear status and row actions.
- Mobile: searchable list cards with key identity/status first; actions in an explicit menu; no page-wide horizontal scroll.
- Preserve pagination, cursor semantics, access scopes, and existing endpoint payloads.

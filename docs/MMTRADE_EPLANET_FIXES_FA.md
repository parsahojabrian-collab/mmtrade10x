# اصلاحات صفحه و پنل ePlanet

این نسخه بر مبنای همان ادغام ce014da و 78c9548 آماده شده و اصلاحات قبلی ربات، پیش‌نمایش و ابزارهای هوم را نیز دارد.

اصلاحات:
- وضعیت completed از ورک‌فلو به‌درستی برمی‌گردد؛ پیشرفت به ۴ از ۴ و ۱۰۰٪ می‌رسد.
- نام کاربر و شناسه حساب در پنل مدیر با textContent ساخته می‌شوند؛ HTML ارسالی کاربر تفسیر نمی‌شود.
- خواندن/نوشتن صف و تصمیم مدیر، قفل دیتابیسی مشترک و تراکنش دارند؛ تأیید ورک‌فلو و نتیجه درخواست با هم commit یا rollback می‌شوند.
- قفل ورک‌فلو بین مسیر قدیمی مدیریت تیم و مسیر جدید ePlanet مشترک است؛ نسخه و ترتیب مراحل حفظ می‌شوند.
- ارسال تکراری، ارسال مرحله قفل‌شده، تأیید حساب متفاوت و بازنویسی فرم تنظیمات قدیمی رد می‌شوند.
- پاک‌سازی تاریخچه درخواست‌های pending را حذف نمی‌کند؛ پرشدن ظرفیت خطای مشخص می‌دهد.
- عنوان تنظیم‌شده نمایش داده می‌شود و مسیر تصاویر در آدرس‌های جایگزین هم درست است.
- صفحه مهمان و پیش‌نمایش مدیریت هیچ درخواست تأیید واقعی ارسال نمی‌کنند؛ دکمه‌ها تا دریافت وضعیت معتبر قفل‌اند.
- علت رد نمایش داده می‌شود و شناسه حساب برای اصلاح مجدد حفظ می‌شود.
- وضعیت قابل به‌روزرسانی است؛ درخواست pending هنگام باز بودن صفحه بررسی می‌شود.
- شکست دریافت وضعیت یا فهرست پس از ثبت موفق، دیگر به‌عنوان شکست ارسال/تصمیم گزارش نمی‌شود.
- لینک‌های اجرایی و HTTP ناامن رد می‌شوند؛ تصاویر محلی آپلودشده پذیرفته می‌شوند.
- خطای نشست مدیر، پنل و صف قبلی را می‌بندد؛ درخواست‌های خصوصی no-store هستند.

شواهد تازه: ۱۸۲ تست رفتاری/قراردادی، npm test و npm run build پاس شدند.
۱۶ تست اختصاصی شامل تراکنش، رقابت دو worker، نقش مدیر، DOM صفحه و جلوگیری از HTML ناامن اضافه شده‌اند.
آزمون بصری Chromium متوقف شد و تکمیل نشده است؛ نتیجه موفق برای آن گزارش نمی‌شود.
اتصال زنده به Telegram، MySQL سرور و استقرار سایت انجام نشده‌اند.

فایل‌ها: apps/api/src/index.ts؛ public/miniapp/p74/eplanet/{app.js,admin.js,index.html,admin.html,styles.css}؛ تست‌ها و مستندات.
ساختار دیتابیس و فایل محیطی تغییر نمی‌کند. فایل نصب فقط پوشه ادغام را تغییر می‌دهد، بکاپ می‌گیرد، تست و build اجرا می‌کند و در صورت شکست برمی‌گرداند. هیچ push، deploy یا restart انجام نمی‌شود.

# حالت فقط مینی‌اپ در پنل سوپرادمین

مبنا: main با کامیت 9097b2cded63ea20da4b6bd3837dbc6b81b8bf61.

مسیر رابط: مدیریت ربات تلگرام ← تنظیمات ربات تلگرام ← «حالت فقط مینی‌اپ — خاموش‌کردن تمام کیبورد ربات» ← ذخیره همه تنظیمات.

این گزینه مستقل از «فعال بودن تنظیمات پیام و منو» است. مقدار پیش‌فرض false است؛ منوهای معمول فعلی حفظ می‌شوند. هنگام فعال‌بودن، middleware قبل از دستورها، دکمه‌ها، contact و callbackهای قدیمی، پیام تعاملی را به ورودی مینی‌اپ هدایت می‌کند. ثبت‌نام تلفنی، رضایت، ایجاد تیکت و منوی سفارشی از طریق دکمه‌های قدیمی اجرا نمی‌شوند. callbackهای قدیمی answer می‌شوند تا حالت انتظار تلگرام باقی نماند.

تلگرام در هر پیام فقط یک reply_markup می‌پذیرد، پس حذف کیبورد قدیمی و نمایش دکمه Web App در دو پیام انجام می‌شود. تنها دکمه عملیاتی جدید، «ورود به مینی‌اپ» است. این گزینه سرویس ربات را خاموش نمی‌کند.

لینک MINI_APP_URL باید HTTPS معتبر و بدون username/password باشد. API قبل از ذخیره فعال‌سازی آن را بررسی می‌کند؛ اگر لینک بعداً خراب شود، ربات راهنمای خطا نشان می‌دهد و منوی معمول را ناخواسته باز نمی‌کند. مدیریت این گزینه فقط برای SUPER_ADMIN است و audit شامل miniAppOnly می‌شود. کلاینت‌های قدیمی که فیلد را نمی‌فرستند مقدار فعلی را حفظ می‌کنند.

تنظیمات ربات ۱۰ ثانیه cache می‌شوند. کاربران موجود پس از پیام یا دکمه بعدی، کیبورد قدیمی‌شان جمع می‌شود؛ حذف خودکار کیبورد تمام کاربران بدون ارسال پیام انجام نمی‌شود. ارسال گروهی خودکار اضافه نشده است. پس از خاموش‌کردن گزینه، /menu یا /start دوباره منوی عادی را باز می‌کند. تنظیمات ۹ دکمه و منوهای سفارشی پاک نمی‌شوند.

این تغییر، مجوزهای محتوای مینی‌اپ را باز نمی‌کند: بخش‌های نیازمند ثبت‌نام تلفنی همچنان برای کاربر ناقص محدودند. کاربر جدید در حالت فقط مینی‌اپ از کیبورد ربات شماره نمی‌فرستد. پیام‌های اتوماسیون و صف اعلان‌ها هم با این گزینه حذف یا متوقف نمی‌شوند؛ دامنه قابلیت، مسیرهای تعاملی و کیبورد ربات است.

## اعتبارسنجی

۹ سناریوی جدید: شروع فقط با Web App و حذف کیبورد؛ جلوگیری از دکمه، contact و فرمان قدیمی؛ callback رضایت قدیمی؛ بازیابی منو بعد از خاموش‌کردن؛ لینک نامعتبر؛ ذخیره و خواندن گزینه مستقل از enabled؛ اعتبارسنجی HTTPS بدون تغییر تنظیمات قبلی؛ حفظ مقدار برای کلاینت قدیمی؛ مجوز سوپرادمین و رد مقدار غیر boolean.

تست‌های API با Fastify.inject و callbackهای واقعی اجرا می‌شوند. تست‌های ربات سورس واقعی را با مرز Telegram و Prisma شبیه‌سازی‌شده اجرا می‌کنند. npm test، npm run build و بررسی syntax اسکریپت‌های پنل پاس شدند. بررسی رابط واقعی تلگرام/مرورگر و دیتابیس واقعی در این محیط انجام نشد.

## آماده‌سازی سورس

اسکریپت MMTrade-Bot-MiniApp-Only.py main را fetch و مبنا را کنترل می‌کند، سپس در worktree/شاخه جدا فایل‌های سورس را می‌نویسد، تست و build می‌گیرد و فقط فایل‌های همین بسته را stage می‌کند. اگر main تغییر کرده باشد متوقف می‌شود. استقرار، commit، push و restart انجام نمی‌دهد. برای استقرار روی سروری که تغییرات محلی دارد، ابتدا فایل MMTrade-Live-Compare.zip باید بررسی شود.

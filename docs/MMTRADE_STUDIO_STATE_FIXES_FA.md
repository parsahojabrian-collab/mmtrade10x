# سورس اصلاح‌شده استودیوی بصری

مبنا: main با SHA a6fca367382e5adf131190f7f09cc288f5212c0c، همراه ادغام تغییرات محلی بررسی‌شده MMTrade-Live-Compare.zip.

اصلاح‌ها:

1. انتقال صفحه یک عملیات هماهنگ محتوا/چیدمان است؛ تا پایان هر دو درخواست ویرایش قفل می‌ماند. خطا، ذخیره و انتشار را تا بارگذاری دوباره می‌بندد.
2. موتور چیدمان نام صفحه و revision را فقط پس از دریافت موفق سند عوض می‌کند؛ خطا یا پاسخ کهنه نمی‌تواند سند قبلی را به صفحه جدید متصل کند.
3. آپلود عنصر، بلوک و پاپ‌آپ مقصد اولیه و session را نگه می‌دارد. پاسخ متعلق به صفحه یا فرم قبلی به مقصد جدید نوشته نمی‌شود. آپلود معلق در محافظ خروج/انتقال حساب می‌شود.
4. پیش‌نمایش Home پیش‌فرض قابل ویرایش است. گزینه مقایسه با نسخه منتشرشده فعال است؛ در آن حالت چیدمان عمومی نمایش داده می‌شود و کشیدن/ویرایش خاموش است. بازکردن ابزار Home به پیش‌نویس برمی‌گردد.
5. فرم پاپ‌آپ baseline، dirty و busy مستقل دارد؛ تعویض فرم با تغییرات ذخیره‌نشده نیازمند تأیید است و ذخیره/آپلود معلق محافظت می‌شود.
6. جابه‌جایی گروهی پیش از تغییر سند، سقف ۵۰۰ تنظیم را بررسی می‌کند؛ عملیات نامعتبر نصفه اعمال نمی‌شود.
7. جست‌وجوی رسانه درخواست آخر را بعد از درخواست جاری اجرا می‌کند و نتیجه کهنه را رندر نمی‌کند. دکمه صفحه‌بندی حین دریافت، شماره صفحه را تغییر نمی‌دهد.
8. واگرد/بازانجام محلی، snapshot محتوا و چیدمان را با هم نگه می‌دارد. بازپخش تاریخچه خودش ورودی تاریخچه جدید ایجاد نمی‌کند. بارگذاری صفحه/بازیابی از سرور یک مرز جدید تاریخچه است؛ Undo جایگزین تاریخچه نسخه‌های سرور نیست.
9. بلوک HTML امن در فهرست، افزودن و ویرایش پشتیبانی می‌شود؛ حداکثر ۱۶۰۰۰ نویسه، با همان renderer و sanitizer موجود. HTML خام اجرا نمی‌شود.

تغییرات لایه‌های پس‌زمینه، مسیرهای اصلی سرور و لینک مشاهده/کپی انتشار از ادغام قبلی حفظ شدند. URL دارایی‌های تغییرکرده نسخه جدید cache دارند.

۱۴ تست رگرسیون جدید روی callbackهای واقعی و DOM/API کنترل‌شده پاس شدند؛ کل npm test و npm run build هم پاس شدند. لمس/drag و لایه‌بندی در Safari واقعی و تست Telegram/MySQL واقعی در این محیط انجام نشدند. پس از استقرار، انتخاب عکس حین آپلود، تعویض صفحه در شبکه کند، پیش‌نمایش Home، Undo جابه‌جایی و هشدار فرم پاپ‌آپ را روی آیفون بررسی کنید.

prepare-studio-fixed.py سورس را در /root/miniapp10x-studio-fixed و شاخه جدا آماده می‌کند و تست و build می‌گیرد. commit، push یا استقرار خودکار ندارد. اگر main با مبنای بسته فرق کند متوقف می‌شود. deploy-studio-fixed.py پس از commit و push به main می‌تواند پیش‌بررسی کند؛ --deploy تعویض صریح نسخه فعال است، با بکاپ و rollback. فایل ناشناخته بازنویسی نمی‌شود و هیچ migration، پاک‌سازی داده، تغییر env یا تنظیم Nginx در بسته نیست.

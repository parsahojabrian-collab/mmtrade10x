# تطبیق نهایی فایل‌های سرور و سورس اصلاح‌شده

مبنای انتشار: main با پیشوند 98daeff و درخت سورس 04030fc48116b8abee328dc08a9361df54fd65c9.
آرشیوهای بررسی‌شده: MMTrade-Live-Compare.zip، MMTrade-Deployment-Unknown-Files.zip و MMTrade-Extra-Assets.zip.

۶۴ مقصد متفاوت به ۳۹ فایل سورس/وب تطبیق داده شدند. محتوای جدید ۷ درس کپی‌ترید با ۲ اسلاید، اصلاح چیدمان و اسکرول درس، ابزار پس‌زمینه چندلایه، ویرایش اندازه پنل درس و مسیرهای ناوبری تازه حفظ شدند. تغییر محلی مربوط به lessonId قدیمی ربات هم با حفظ اعتبارسنجی و حالت فقط مینی‌اپ ادغام شد؛ تست رگرسیون این رفتار اضافه شده است.

نسخه‌های قدیمی optimizer، فایل استودیو و کتابخانه وب جای اصلاح‌های main را نگرفتند. درخواست popup-debug که بخشی از سورس متفاوت قدیمی بود، وارد انتشار نشد. طراحی شیشه‌ای و sanitizer موجود main حفظ شدند.

فایل مشترک تایپوگرافی به سورس اصلی اضافه شد. هیچ فایل Peyda در سرور وجود ندارد؛ ارجاع شبکه‌ای به فونت‌های ناموجود حذف شد و Peyda محلی سیستم یا Doran فعلی به‌عنوان fallback استفاده می‌شود. تصویر JPG ناموجود به PNG موجود ارجاع داده شد. فونت باینری جدیدی تولید/نصب نشده است. آدرس دارایی‌های تغییرکرده cache version تازه دارد.

بسته prepare-live-sync.py بر اساس مبنای دقیق main، worktree جدا می‌سازد، فایل‌های کامل را می‌نویسد، تست و build می‌گیرد و فقط فایل‌های بسته را stage می‌کند. commit/push توسط فرمان‌های تحویلی کاربر انجام می‌شود. اگر SHA/درخت مبنا تغییر کرده باشد بسته متوقف می‌شود.

deploy-live-sync.py سورس را با manifest و main تطبیق می‌دهد. hashهای دقیق ۶۴ مقصد بررسی‌شده و CSS اضافی به مجموعه نسخه‌های شناخته‌شده اضافه شده‌اند؛ محافظ فایل ناشناخته حذف یا عمومی نشده است. اگر پس از آرشیو فایل جدیدی عوض شده باشد، استقرار متوقف می‌شود. پیش‌بررسی روی بازسازی فایل‌های ارسال‌شده از سرور باید بدون اختلاف ناشناخته تمام شود.

--deploy بکاپ فایل‌های تغییرکرده منبع، static و compiled را می‌گیرد، API و ربات فعال را برای تعویض هماهنگ متوقف و دوباره راه‌اندازی می‌کند. در خطا فقط فایل‌های تعویض‌شده بازگردانده می‌شوند. فایل‌های env، دیتابیس، uploads و تنظیمات Nginx تغییر نمی‌کنند و migration اجرا نمی‌شود. وجود پردازش ربات جای تست واقعی Telegram را نمی‌گیرد. پس از نصب، پنل را full refresh و ذخیره/انتشار و یک پیام /start را بررسی کنید.

تست‌های سورس و build با نسخه یکپارچه پاس شدند؛ تست واقعی روی Safari آیفون و دیتابیس/Telegram تولید در این محیط انجام نشد.

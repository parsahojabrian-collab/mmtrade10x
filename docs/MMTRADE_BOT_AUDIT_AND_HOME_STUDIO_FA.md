## بررسی و اصلاح ربات تلگرام

مسیرهای شروع، عضویت، رضایت، دریافت شماره، منو، محتوای سفارشی، پشتیبانی، ادغام ثبت‌نام وب، یادآوری، اعلان و خاموش‌شدن سرویس بررسی شدند.

| ایراد | رفتار اصلاح‌شده | بررسی |
|---|---|---|
| بازنویسی مقصد خصوصی با شناسهٔ گروه | فقط گفتگوی خصوصی پردازش می‌شود و مقصد از شناسهٔ تلگرام مشتق می‌شود | تست middleware و اعلان |
| اجراشدن دکمهٔ غیرفعال | متن دکمهٔ غیرفعال دیگر عملیات پشتیبانی/منو را اجرا نمی‌کند | تست رفتاری handler |
| باقی‌ماندن برچسب‌های قدیمی در کش | بازنشانی تنظیمات، برچسب‌های پیش‌فرض را هم بازمی‌گرداند | تست انقضای کش |
| دکمهٔ رضایت نامنطبق با تنظیمات | متن نمایشی و تشخیص ربات از یک تنظیم می‌آیند | تست کیبورد |
| قبول رضایت قبلی پس از انصراف جدید | جدیدترین تصمیم همان کانال و نسخه بررسی می‌شود؛ ثبت شماره نیز داخل تراکنش دوباره بررسی می‌کند | تست رضایت، انصراف و تماس |
| عقب‌رفتن حساب کامل با دکمهٔ قدیمی | عضویت و رضایت قدیمی وضعیت حساب کامل را عقب نمی‌برند | تست callback |
| ناهماهنگی مرحله و وضعیت دریافت شماره | PHONE_PENDING و بازگشت به رضایت با وضعیت ثبت‌نام همگام‌اند | تست وضعیت |
| باقی‌ماندن username حذف‌شده | فیلد حذف‌شدهٔ تلگرام در دیتابیس null می‌شود | تست upsert |
| ایجاد تیکت بدون پیام یا عملیات نیمه‌کارهٔ پشتیبانی | ایجاد، پیام و بستن گفتگو تراکنشی‌اند و قفل مشترک کاربر می‌گیرند | تست rollback و گفتگو |
| حذف سوابق هنگام ادغام وب | پیشرفت بیشتر درس، پروفایل تکمیل‌شده و صف پیام‌ها حفظ می‌شوند؛ سوابق غیرقابل‌ادغام بدون حذف برای بررسی باقی می‌مانند | تست ادغام و تعارض |
| جا ماندن کاربران بعد از صد نفر اول | مرور یادآوری‌ها cursor دارد | تست صفحه‌بندی |
| حذف اعلان به‌خاطر خطای موقت | retry با زمان‌بندی ذخیره‌شده و رعایت retry_after؛ ۴۰۳ و سقف تلاش خاتمه می‌دهند | تست صف |
| قطع دیتابیس با worker در حال اجرا | توقف timer و انتظار برای کار در حال اجرا؛ پس از توقف، کار تازه claim نمی‌شود | تست shutdown |
| ارسال یادآوری قبل از رد حالت startup نامعتبر | حالت polling قبل از اتصال/ارسال بررسی می‌شود | تست startup |
| ناپدیدشدن بی‌توضیح فایل پشتیبانی | ربات صریحاً می‌گوید فایل/صدا ثبت نشده و متن لازم است | مسیر fallback |

پشتیبانی فایل، صدا و تصویر همچنان قابلیت این نسخه نیست؛ ثبت متن پشتیبانی پشتیبانی می‌شود.
ممیزی کد و تست محلی، به معنی تضمین نبود هیچ باگ یا آزمودن اتصال واقعی تلگرام/MySQL نیست.
ارسال پیام با بازیابی پس از restart تضمین دقیقاً یک‌بار ندارد؛ این محدودیت مستقل Telegram Bot API باقی است.

## همهٔ ابزارهای Object Home در استودیوی بصری

مسیر: استودیوی بصری ← خانه ← «◈ آبجکت هوم».
ورودی قدیمی Object Studio هم همین استودیوی یکپارچه را باز می‌کند.

- روشن/خاموش‌کردن هوم و ویرایش برند و زیرعنوان.
- عنوان، لینک، زمان و پوستر ویدیو؛ آپلود، عرض، ارتفاع و جای کادر.
- تیتر مسیر و تعداد ۳ تا ۸ پله؛ افزودن/حذف، نام، لینک، موقعیت، اندازه و چیدمان خودکار.
- آبجکت تصویر، متن، شکل، نور و پرچم؛ نمونه‌های مکعب/سکه، تکثیر/حذف، قفل/نمایش، لایه، رنگ، چرخش و شفافیت.
- انیمیشن، مدت، تأخیر و نمایش آبجکت در تعداد پله‌های مختلف.
- پس‌زمینهٔ مستقل هر کوه، آپلود بهینه و انتخاب از همان کتابخانهٔ مشترک.
- انتخاب مستقیم عناصر صفحه، جایگذاری/اندازه و تنظیمات متن، رنگ، حاشیه و تایپوگرافی.
- متن و لینک پیشرفت و CTA.
- کنترل‌های منوی قدیمی هوم برای پیش‌نمایش حفظ شده‌اند و به همین نام مشخص‌اند؛ منوی سراسری فعال همچنان از بخش «نوار پایین Mini App» مدیریت می‌شود.
- انتخاب موبایل/دسکتاپ از همان پیش‌نمایش استودیو انجام می‌شود.

۴۰ تابع ابزار از ۴۲ تابع ویرایشگر قبلی حفظ شده‌اند؛ دو عملیات مستقل open/saveDraft جای خود را به بازکردن و ذخیرهٔ مشترک استودیو داده‌اند.
فایل inline قدیمی حذف و ابزارها به home-object-editor.js و home-object-editor.css منتقل شده‌اند.
یک نشانگر #p74-home-config داخل همان blocks فعلی نگهداری می‌شود؛ بلوک‌های دیگر حفظ می‌شوند.
انتشار محتوا و چیدمان، بررسی revision، تاریخچهٔ جفت‌شده، بازیابی پیش‌نویس و محافظ خروج همچنان مشترک‌اند.
لینک دو پلهٔ اول اکنون برای تنظیمات جدید قابل ویرایش است؛ تنظیمات قدیمی مسیر قبلی خود را حفظ می‌کنند.
پیش‌نمایش تاریخی فقط‌خواندنی است و تنظیمات زندهٔ پنل نمی‌تواند آن را بازنویسی کند.

## شواهد

- ۱۶۶ تست رفتاری/قراردادی پاس شدند؛ npm test و npm run build پاس شدند.
- در Chromium واقعی با API محلی کنترل‌شده: ویرایش برند، ساخت آبجکت، ویرایش لینک پلهٔ اول، جابه‌جایی پله، انتخاب پس‌زمینه از کتابخانه، آپلود قطعه‌ای پوستر، ذخیره و انتشار مشترک، تاریخچهٔ فقط‌خواندنی و نمایش موبایل پاس شدند.
- ساختار دیتابیس، فایل‌های محیطی و تنظیمات Nginx تغییر نکرده‌اند.
- سایت فعال، اتصال واقعی تلگرام و دیتابیس زنده تست/تغییر داده نشده‌اند.

اسکریپت نصب فقط worktree در حال ادغام با دو commit بالا را می‌پذیرد؛ سورس کامل و index را بکاپ می‌گیرد، فایل‌های ناشناخته را بازنویسی نمی‌کند و تست/build را اجرا می‌کند.
در صورت شکست، سورس و index قبلی را بازمی‌گرداند.
هیچ commit، push، deploy یا restart خودکار انجام نمی‌شود.

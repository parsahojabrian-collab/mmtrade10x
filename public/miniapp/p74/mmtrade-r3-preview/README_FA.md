# MMTrade 10X — نسخه R3 / تطبیق بصری آیتم‌ها

این پروژه یک دموی مستقل و **بدون نصب روی سرور** است که بر اساس رفرنس تأییدشده هفت‌مرحله‌ای `a_highly_polished_cinematic_ui_mockup_in_persian.png` طراحی شده است. هدرهای کشویی و باکس‌های شیشه‌ای با CSS ساخته شده‌اند؛ تنها آبجکت‌های سه‌بعدی از WebP شفاف استفاده می‌کنند.

## ساختار کامپوننت‌ها

**مشترک (یک‌بار تعریف شده):**
- `.mm-stage__head`: کپسول عنوان Liquid Glass با نوار انعکاس و Deep Glow
- `.mm-stage__icon` و `.mm-stage__toggle`: آیکون و فلش تعاملی
- `.mm-stage__inner`: پنل شیشه‌ای محتوای بازشده
- `.mm-feature`, `.mm-feature__copy`, `.mm-art`: چینش تصویر/عنوان/توضیح
- `.mm-mini-grid`, `.mm-mini`: کارت‌های سه‌ستونه
- `.mm-step-list`, `.mm-cta`: گام‌های آموزشی و CTA

**اختصاصی:**
1. معرفی MMTrade: لوگوی کوهی فلزی + سه ویژگی
2. چالش 10X: نماد پرچم و 10X + سه ویژگی
3. دلیل راه‌اندازی: هدف سه‌بعدی + چهار تیک
4. تیم و استراتژی: شطرنج با Deep Glow + سه ویژگی
5. مقایسه دو روش ترید: قرمز/سبز + دو فهرست توضیح
6. راهنمای استفاده: لپ‌تاپ ePlanet + چهار گام
7. ثبت‌نام: کلیپ‌بورد سه‌بعدی + CTA دمو

## تطبیق‌های R3

- هدرها تیره‌تر شدند تا به شیشه دودی و لبه‌های زمردی رفرنس نزدیک‌تر باشند؛ در مرکز هدر از پس‌زمینه تصویرشده و مات استفاده نشده است.
- فاصله و ارتفاع ردیف‌های بسته به چیدمان هفت‌مرحله‌ای رفرنس نزدیک‌تر شده است.
- ترتیب و عبارات کارت‌های کوچک و فهرست‌ها به متن رفرنس نزدیک‌تر شده است.
- لایه‌های Deep Glow و اندازه آبجکت‌های اصلی تنظیم شده است.
- هر باکس فقط در محل خودش باز می‌شود؛ روی یک مرحله دیگر کلیک کنید تا مرحله قبلی بسته شود.

## نصب و اجرا

1. فایل ZIP اجرایی را در مسیر استاتیک دلخواه **استخراج** کنید.
2. `index.html` را از یک وب‌سرور استاتیک باز کنید. ساختار `assets/` را حفظ کنید.
3. برای استفاده از فونت **Doran**، نسخه مجاز فایل را در `fonts/Doran.woff2` قرار دهید. فونت به دلیل نبود فایل دارای مجوز در خروجی، ضمیمه نشده است.
4. برای ادغام در مینی‌اپ موجود، پیش از جایگزینی یا درج، مسیرها و تداخل CSS را در محیط تست بررسی کنید. این پکیج هیچ فایل زنده سایت را تغییر نداده است.
5. CTA صرفاً دمو است؛ بدون API و بدون ارسال داده یا ثبت‌نام واقعی.

## فایل‌ها

- `styles.css`: پایه مشترک
- `r2-reference.css`: تطبیق ساختار و چیدمان
- `r3-precision.css`: اصلاحات دقیق‌تر روی رفرنس
- `app.js`: کنترل انحصاری بازشدن مراحل و CTA نمایشی
- `assets/*.webp`: آبجکت‌ها و انعکاس کادر، دارای alpha
- `previews/*.png`: خروجی واقعی مرورگر برای هفت مرحله
- `previews/contact_sheet_r3_reference_ratio.jpg`: مقایسه بصری هفت بخش با چینش ۲×۴
- `TEST_RESULTS.json`: گزارش بررسی بازشدن مراحل، عدم اسکرول افقی و بارگذاری تصویر

## مرز تأیید

رندر مرورگری بررسی شده، اما **تطابق پیکسلی قطعی** قبل از بارگذاری فونت Doran واقعی و بررسی دستی در خود مینی‌اپ ادعا نمی‌شود. افکت `backdrop-filter` بسته به مرورگر و دستگاه اندکی متفاوت خواهد بود. هدف 10X به معنای سود تضمینی نیست.
